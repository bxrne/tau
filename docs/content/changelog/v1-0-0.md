## 1.0.0 (2026-05-27)

### Features

- Added `tauctl` to manage multiple connections and multi-user workflows.
- Implemented auto-compaction, reductions, and aggregation functions.
- Improved benchmark orchestration and Prometheus metrics, with example
  datasets and a client-side `load` command for bulk ingest.
- Added derived-lens cycle detection, fixed range queries on aggregate lenses,
  and expanded `SHOW` commands with multi-append and CSV import support.
- Introduced the full rewrite plus plus release.
- Added TLS, encryption, and user support.
- Added WAL compaction, schema persistence, WAL failure handling, and disk
  backend append fixes.

### Bug fixes

- Fixed release build and added licensing metadata.

### Performance

- Additional performance improvements and benchmarking updates.
